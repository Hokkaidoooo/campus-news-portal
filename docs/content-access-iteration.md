# 正文阅读与账号权限

日期：2026-10-15。

## 阅读行为

首页、全部动态和全部公告中的标题会进入正文。新闻与通知共用 `/article` 页面和 `/api/article` 查询逻辑，路径随应用上下文生成。正文包含标题、发布时间、保留换行的内容及返回列表入口。无效地址返回 400，已删除或不存在的记录返回 404，并提供返回入口。

通知列表原来把全部记录显示了两次，现在按两列分配，每条记录只显示一次。公开查询复用现有内容服务，不新增另一份内容存储；原列表接口不变。系统尚未提供草稿或审核状态，新闻和通知表中的记录都属于公开内容。

## 权限与兼容影响

这是新增的权限策略，旧版本只要求登录，不承诺管理员与普通用户的权限分工。

| 当前账号状态 | 内容、栏目与上传 | 账号管理 |
| --- | --- | --- |
| 有效管理员 | 允许 | 允许 |
| 有效普通用户 | 允许 | 403 |
| 未配置的角色 | 403 | 403 |
| 已停用、已删除或未登录 | 401 | 401 |

唯一授权入口为 `AllFilter`。管理员角色和编辑角色从 `WEB-INF/web.xml` 的 `AccessControl` 初始化参数读取，页面使用同一结果显示菜单和角色选项。参数为空或两个角色相同时部署明确失败。角色标签调整后需同步数据库中对应账号并重新部署；初始账号 CLI 默认写入 `管理员`。

过滤器每次按会话中的账号 ID 查询当前记录，刷新显示名称与角色。停用或删除会撤销旧会话；重新启用后必须重新登录，旧会话不会复活。降权立即影响下一次请求，普通用户不能通过自己的用户 ID、直接管理 JSP 或 GET/POST 用户接口修改角色。数据库读取失败会暴露为服务器错误，不沿用过时的会话权限。已开始执行的请求不会被中途回滚。

## 文本契约

所有内容表单使用普通文本。多行正文使用 `textarea`，页面通过 JSTL `c:out` 输出标题、正文、账号、查询值与数据属性。编辑、删除操作先从数据属性读取原始 ID，再做 URL 编码；数据不嵌入 JavaScript 字符串。消息弹窗通过文本节点显示。

已有 HTML 片段会以文字显示，编辑再提交仍保留文本内容。表单不再初始化未实际使用的富文本编辑器和缺失的栏目函数；这同时避免编辑页请求不存在的编辑器脚本。密码输入不回显哈希，修改账号时留空保留原密码。

## 验证入口

```powershell
mvn -B test
mvn -B -Pintegration verify
```

集成测试需要独立 MySQL 服务和已安装的 Playwright 浏览器，配置见根 README。`PortalIT` 自建随机测试库，实际部署 WAR，分别在 ROOT 与 `/news` 启动独立 Tomcat。静态编码断言比较 HTTP 响应与被部署 WAR 内的字节，避免把当前源码误当成历史 WAR 的内容。

- `ArticleServletTest`：唯一参数、类型和 ID 边界、400/404、正文 JSON/页面共用数据、数据库异常传播。
- `AllFilterTest`：匿名访问、角色矩阵、当前身份刷新、停用/删除/降权、未知角色、配置错误与数据库失败。
- `PortalIT`：真实 HTTP 与数据库验证普通用户不能提权、停用与删除撤销旧会话、恢复账号不复活旧会话、同一会话权限随角色变化。
- `browser-content-checks.mjs`：实际点击新闻/通知、直达与刷新、错误页面、移动布局；四类内容和账号中的脚本文本不执行，编辑值保留，引号及检索条件完整往返。

旧 WAR 已使用同一浏览器回归真实复现：写入包含脚本的新闻后，后台列表执行了脚本，`data-portal-xss` 为 `executed`。摘录见 [旧版失败证据](validation/content-access-20261015/before-xss.log)。

## 本机实际结果

- JDK 8、Maven 3.9.9、独立 MySQL 5.7.17、Tomcat 9.0.111、Playwright 1.56.1 与系统 Edge；数据库目录为本轮新建，未使用现有业务库。
- 19 项单元测试及 5 项集成测试全部通过，0 失败、0 错误、0 跳过；WAR 构建成功。
- 同一 WAR 分别部署于 ROOT 与 `/news`。真实 HTTP 验证管理员、普通编辑、提权拒绝、停用、恢复、降权及删除后的会话行为。
- 两种部署均通过浏览器安全编辑 5 类对象、新闻与通知阅读、刷新、直接地址、400/404、日期格式和手机布局验证。结果：[ROOT](validation/content-access-20261015/root-browser.json)、[/news](validation/content-access-20261015/news-browser.json)。
- 已实际查看正文截图：[桌面](validation/content-access-20261015/root-article.png)、[手机](validation/content-access-20261015/root-article-mobile.png)。公开页面只显示内容与阅读导航。

本机证据使用 MySQL 5.7；仓库 CI 继续在 MySQL 8 上执行相同验证，结果以对应提交的 Actions 记录为准。
